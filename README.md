# Site Dra. Fernanda Vale

Site institucional responsivo em HTML, CSS e JavaScript puro.

## Como executar

Abra a pasta no VS Code e use uma destas opções:

1. Abra `index.html` diretamente no navegador.
2. Use a extensão Live Server e escolha **Open with Live Server**.
3. No terminal, execute `npx serve .` e abra o endereço indicado.

## Estrutura

- `index.html`: conteúdo e estrutura do site
- `styles.css`: identidade visual e responsividade
- `script.js`: menu mobile, animações e ano automático
- `assets/`: fotografias usadas no site
